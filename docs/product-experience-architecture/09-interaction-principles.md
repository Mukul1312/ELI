# Interaction Principles

The Eli product should feel calm in motion, low-pressure in action, and clear in focus.

Interaction design is one of the main ways the product either reinforces or violates the brand system.

## 1. One Calm Focal Action

Each important surface should make one action feel clearly primary.

That action should:

- feel easy to locate
- feel emotionally acceptable
- avoid competing with equally weighted alternatives

If every action is emphasized, the product becomes anxious.

## 2. Invite, Don't Command

Actions should feel like invitations into motion, not demands for performance.

This means:

- CTA copy should be clear, not harsh
- action hierarchy should guide rather than pressure
- commitment should feel bounded rather than dramatic

## 3. Reduce Ceremony Around Starting

Beginning should require as little ceremonial friction as possible.

Avoid:

- long setup rituals
- too many up-front decisions
- commitment steps that feel heavier than the study task itself

The product should help a student cross the threshold into action quickly and calmly.

## 4. Preserve Reversibility Where Appropriate

When the student is under load, the product should not make every choice feel irreversible.

Where possible:

- offer bounded actions
- let the user adjust without penalty
- avoid commitment framing that raises emotional stakes unnecessarily

## 5. Motion Should Settle

Motion should:

- orient
- soften transitions
- clarify state changes
- make the product feel grounded

Motion should not:

- dramatize progress
- create spectacle
- add stimulation for its own sake

## 6. Protect Working Attention

During active study, the product should compete as little as possible with the actual task.

That means:

- fewer interruptions
- fewer visual grabs
- less secondary movement
- less unnecessary interaction density

## Interaction Test

The interaction model is correct when:

- the next action feels possible
- starting feels easier than delaying
- the product becomes quieter as the student moves deeper into work
- success feels grounded rather than celebrated theatrically

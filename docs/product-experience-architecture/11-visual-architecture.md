# Visual Architecture

The Eli product should feel like a quiet room for study rather than a software dashboard.

Visual architecture is not just decoration. It is one of the main regulatory tools the product uses to lower pressure, preserve focus, and make progress feel grounded.

## Visual Goal

At the product level, Eli should feel:

- warm but restrained
- clear but not clinical
- tactile but not ornamental
- calm but not empty in a generic way

## Core Visual Structure

### Warm paper field
The background should create room to breathe. Large areas of calm space are part of the product's function, not a sign that something is missing.

### Charcoal structure
Primary and secondary structure should rely on charcoal tones that feel human and honest rather than stark or technical.

### Terracotta invitation
Action emphasis should feel like an invitation into motion, not a command center prompt.

### Green confirmation
Green should remain rare and meaningful. It should signal grounded confirmation, not generic accent color usage.

## Product-Level Hierarchy

The visual hierarchy should usually follow this order:

1. the emotional center of the current moment
2. the next practical action
3. supporting structure and context
4. secondary metadata

If metadata or chrome competes with the focal action, the product has become visually noisy.

## Typography In Product

The product should use Eli's dual typographic roles:

- **Voice Type** when Eli's presence or reflection matters
- **Structure Type** when the interface needs to orient, label, or organize action

The contrast between these roles should feel calm and intentional, not theatrical.

## Brand Presence In Product

Brand presence should be embedded through:

- tone
- spacing
- hierarchy
- semantic color use
- restraint

It should not depend on:

- repeated logos
- decorative watermark behavior
- loud illustration systems
- extra chrome added to "make it feel branded"

## Product Visual Rule

The product should become quieter as the student moves deeper into work.

This means:

- strongest atmospheric framing near entry and orientation
- clearest action framing at commitment
- least visual competition during active study
- most meaningful visual confirmation at closure

## Failure Mode

If the product starts to feel like branded productivity software with softer colors, the visual architecture has failed.
